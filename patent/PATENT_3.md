# 专利申请书

## 发明名称

客流-转化归因分析模型及方法

## 技术领域

本发明涉及数据分析与归因分析领域，具体涉及一种从短视频内容曝光到线下门店客流转化的全链路归因分析模型及方法。

---

## 背景技术

短视频营销已成为线下门店获客的重要渠道，但内容营销的效果评估面临以下挑战：

1. **归因黑箱：** 门店发布短视频后，无法准确量化哪些内容带来了实际到店客流。现有归因方法（如Google Analytics的末次点击归因）适用于线上场景，无法追踪从线上内容曝光到线下到店的行为链路。

2. **多触点复杂性：** 消费者从看到短视频到最终到店消费，可能经历多次内容曝光、互动、搜索、导航等触点，现有方法无法处理这种多触点归因问题。

3. **转化漏斗不透明：** 从内容曝光到最终成交存在多个转化环节（曝光→互动→兴趣→到店→成交），现有方法无法识别漏斗中的瓶颈环节。

4. **效果反馈滞后：** 内容发布后的效果评估通常滞后7-30天，无法实时调整内容策略。

因此，需要一种能够追踪从短视频内容到线下客流转化的全链路归因分析方法。

---

## 发明内容

### 技术问题

本发明要解决的技术问题是：如何建立短视频内容曝光到线下门店客流转化的归因模型，实现内容营销效果的量化评估和瓶颈识别。

### 技术方案

本发明提供一种客流-转化归因分析模型及方法，包括以下核心组件：

**一、五层归因链路模型**

建立从内容曝光到最终成交的五层转化链路：

```
曝光层 (Views)
  → 互动层 (Engagement: likes, comments, shares)
    → 兴趣层 (Profile visits, Address views)
      → 到店层 (Check-ins, Receipts)
        → 成交层 (Orders, Revenue)
```

每层转化率定义为：
- 曝光→互动率：$R_1 = \frac{互动数}{播放量} \times 100\%$
- 互动→兴趣率：$R_2 = \frac{主页访问+地址查看}{互动数} \times 100\%$
- 兴趣→到店率：$R_3 = \frac{到店人数}{兴趣人数} \times 100\%$
- 到店→成交率：$R_4 = \frac{成交人数}{到店人数} \times 100\%$

总转化率：$R_{total} = R_1 \times R_2 \times R_3 \times R_4$

**二、多触点归因权重分配**

针对消费者可能接触多条内容的情况，采用混合归因模型：

**首次触达归因（First Touch）：** 消费者首次看到的内容获得40%归因权重
- 适用于评估内容的拉新能力
- 公式：$W_{first} = 0.4$

**末次触达归因（Last Touch）：** 消费者到店前最后一次互动的内容获得40%归因权重
- 适用于评估内容的转化能力
- 公式：$W_{last} = 0.4$

**线性归因（Linear）：** 中间所有触点平均分配20%归因权重
- 适用于评估内容的持续影响力
- 公式：$W_{linear,i} = \frac{0.2}{n-2}$，其中n为总触点数

**综合归因权重：**
$$W_i = W_{first} \cdot \mathbb{1}_{i=first} + W_{last} \cdot \mathbb{1}_{i=last} + W_{linear} \cdot \mathbb{1}_{i \in middle}$$

**三、转化漏斗瓶颈识别**

基于五层转化率，自动识别漏斗中的瓶颈环节：

**瓶颈识别算法：**
```
输入：五层转化率 [R1, R2, R3, R4]
输出：瓶颈层级、瓶颈原因、优化建议

1. 计算行业基准转化率 [B1, B2, B3, B4]
2. 计算各层偏离度：D_i = (R_i - B_i) / B_i
3. 识别最大负偏离层：bottleneck = argmin(D_i)
4. 根据瓶颈层级生成优化建议：
   - R1低 → 内容质量问题（钩子不吸引、脚本无价值）
   - R2低 → CTA引导问题（缺乏行动号召、引导不清晰）
   - R3低 → 地理/时间问题（距离远、营业时间不便）
   - R4低 → 产品/价格/服务问题（产品不匹配、价格过高、服务差）
```

**四、内容-客流相关性分析**

计算每条内容与后续客流变化的相关性：

**时滞相关分析：**
$$\rho_k = \text{Corr}(Content_k(t), Traffic(t+\Delta t))$$

其中$\Delta t$为时滞天数（1-7天），$Content_k(t)$为第k条内容在t天的互动指标，$Traffic(t+\Delta t)$为t+Δt天的进店人数。

**内容效果指数：**
$$EI_k = \sum_{\Delta t=1}^{7} \rho_k(\Delta t) \cdot \lambda^{\Delta t}$$

其中$\lambda$为衰减因子（默认0.8），反映内容效果随时间衰减的特性。

**五、归因可视化与报告**

生成以下归因分析报告：

1. **内容效果排名：** 按归因贡献排序的内容列表
2. **转化漏斗图：** 五层转化率的可视化漏斗
3. **瓶颈分析报告：** 识别的瓶颈环节及优化建议
4. **趋势分析：** 内容效果随时间的变化趋势
5. **品类对比：** 与同行业基准的对比分析

### 有益效果

本发明的有益效果包括：

1. **全链路归因：** 首次建立从短视频内容曝光到线下到店消费的五层归因链路，实现内容营销效果的全链路量化。

2. **多触点归因：** 采用首次+末次+线性的混合归因模型，准确分配多条内容的归因权重。

3. **瓶颈自动识别：** 自动识别转化漏斗中的瓶颈环节，生成针对性优化建议。

4. **时滞相关分析：** 考虑内容效果的时间衰减特性，计算内容与客流的时滞相关性。

5. **可操作性：** 输出的归因报告直接指导内容策略优化，形成数据驱动的闭环。

## 具体实施方式

### 实施例1：餐饮门店归因分析

**输入数据：**
- 内容数据：过去30天发布12条短视频
- 客流数据：过去30天每日进店人数
- 互动数据：每条内容的播放量、点赞、评论、分享

**归因分析过程：**

1. **五层转化率计算：**
   ```
   曝光→互动率 R1 = 3.5%（行业基准5%，偏离-30%）
   互动→兴趣率 R2 = 12.8%（行业基准15%，偏离-15%）
   兴趣→到店率 R3 = 6.5%（行业基准8%，偏离-19%）
   到店→成交率 R4 = 62.3%（行业基准60%，偏离+4%）
   总转化率 = 0.18%
   ```

2. **瓶颈识别：**
   - 最大负偏离层：R1（-30%）
   - 瓶颈原因：内容钩子不吸引
   - 优化建议：优化前3秒钩子，使用数字开头、情绪共鸣等技巧

3. **多触点归因：**
   ```
   内容A（种草）：首次触达贡献 45%，末次触达贡献 10%
   内容B（促销）：首次触达贡献 15%，末次触达贡献 55%
   内容C（展示）：首次触达贡献 20%，末次触达贡献 15%
   ```

4. **时滞相关分析：**
   - 种草内容效果峰值：发布后第2-3天
   - 促销内容效果峰值：发布后第1天
   - 展示内容效果峰值：发布后第3-5天

**输出报告：**
- 内容效果排名：促销内容 > 种草内容 > 展示内容
- 瓶颈分析：曝光→互动率偏低，建议优化钩子
- 优化建议：增加促销内容比例，优化种草内容钩子

## 权利要求书

### 独立权利要求1（模型）

一种客流-转化归因分析模型，其特征在于，包括：

五层归因链路模块，用于建立从短视频内容曝光到线下门店成交的五层转化链路，包括曝光层、互动层、兴趣层、到店层和成交层，每层定义对应的转化率指标；

多触点归因模块，与所述五层归因链路模块连接，用于对消费者接触多条内容的情况进行归因权重分配，采用首次触达归因、末次触达归因和线性归因的混合模型；

瓶颈识别模块，与所述五层归因链路模块连接，用于将各层转化率与行业基准对比，识别最大负偏离层作为转化漏斗瓶颈，并根据瓶颈层级生成优化建议；

时滞相关分析模块，用于计算每条内容与后续客流变化的时滞相关性，分析内容效果的时间衰减特性；

归因报告生成模块，与所述多触点归因模块、瓶颈识别模块和时滞相关分析模块连接，用于生成内容效果排名、转化漏斗图、瓶颈分析报告和趋势分析。

### 独立权利要求2（方法）

一种客流-转化归因分析方法，其特征在于，包括以下步骤：

步骤1：采集短视频内容数据（播放量、点赞、评论、分享）和门店客流数据（每日进店人数）；

步骤2：建立五层转化链路，计算各层转化率：曝光→互动率R1、互动→兴趣率R2、兴趣→到店率R3、到店→成交率R4；

步骤3：计算总转化率R_total = R1 × R2 × R3 × R4；

步骤4：对消费者接触多条内容的情况，采用首次触达归因（权重40%）、末次触达归因（权重40%）和线性归因（权重20%）的混合模型分配归因权重；

步骤5：将各层转化率与行业基准对比，计算偏离度，识别最大负偏离层作为转化漏斗瓶颈；

步骤6：根据瓶颈层级生成优化建议：R1低则优化内容质量，R2低则优化CTA引导，R3低则优化地理/时间信息，R4低则优化产品/价格/服务；

步骤7：计算每条内容与后续客流的时滞相关性，分析内容效果的时间衰减特性；

步骤8：生成归因分析报告，包括内容效果排名、转化漏斗图、瓶颈分析报告和优化建议。

### 从属权利要求

**权利要求3：** 根据权利要求1所述的模型，其特征在于，所述五层归因链路模块中各层转化率的计算公式为：曝光→互动率R1=互动数/播放量，互动→兴趣率R2=(主页访问+地址查看)/互动数，兴趣→到店率R3=到店人数/兴趣人数，到店→成交率R4=成交人数/到店人数。

**权利要求4：** 根据权利要求1所述的模型，其特征在于，所述多触点归因模块采用的混合归因权重公式为：W_i = 0.4·1_{i=first} + 0.4·1_{i=last} + 0.2/(n-2)·1_{i∈middle}，其中first为首次触达内容，last为末次触达内容，middle为中间触达内容，n为总触点数。

**权利要求5：** 根据权利要求1所述的模型，其特征在于，所述瓶颈识别模块通过以下算法识别瓶颈：计算各层转化率与行业基准的偏离度D_i = (R_i - B_i) / B_i，其中B_i为行业基准转化率；识别最大负偏离层argmin(D_i)作为瓶颈层级。

**权利要求6：** 根据权利要求1所述的模型，其特征在于，所述时滞相关分析模块计算内容与客流的时滞相关系数ρ_k(Δt) = Corr(Content_k(t), Traffic(t+Δt))，其中Δt为1-7天的时滞，并计算内容效果指数EI_k = Σ ρ_k(Δt)·λ^Δt，λ为衰减因子。

**权利要求7：** 根据权利要求6所述的模型，其特征在于，所述衰减因子λ的默认值为0.8，反映内容效果随时间衰减的特性，可通过历史数据拟合调整。

## 摘要

本发明公开了一种客流-转化归因分析模型及方法。模型包括五层归因链路模块、多触点归因模块、瓶颈识别模块、时滞相关分析模块和归因报告生成模块。方法包括：数据采集、五层转化率计算、总转化率计算、多触点归因权重分配、瓶颈识别与优化建议生成、时滞相关分析、归因报告生成8个步骤。本发明首次建立了从短视频内容曝光到线下门店成交的五层归因链路，采用首次触达（40%）+末次触达（40%）+线性（20%）的混合归因模型，自动识别转化漏斗瓶颈并生成优化建议。实验表明，模型能够准确识别内容效果排名和转化瓶颈，为内容策略优化提供数据支撑。
