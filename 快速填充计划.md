#### 1. AI脚本生成服务 (高优先级)
**问题**: ContentController中generateScript返回硬编码内容，未接入真实AI

**解决方案**:
```java
// 新建 AIScriptService.java
@Service
public class AIScriptService {
    
    public ScriptResult generateScript(Long calendarId, String shopName, String category, String city) {
        // 调用AI API生成真实脚本
        String prompt = buildScriptPrompt(shopName, category, city);
        String response = aiClient.chat(prompt);
        return parseScriptResponse(response);
    }
    
    private String buildScriptPrompt(String shopName, String category, String city) {
        return String.format("""
            你是一位短视频脚本专家，为%s类型的店铺生成抖音脚本。
            店铺名称：%s
            品类：%s
            城市：%s
            
            生成7天内容计划，包含：
            - 每天的开场钩子(3秒)
            - 正文内容(30秒)
            - 行动号召(5秒)
            - 话题标签(5个)
            - 最佳发布时间
            """, category, shopName, category, city);
    }
}
```

**调用示例**:
```java
@PostMapping("/script/generate")
public Map<String, Object> generateScript(@RequestBody Map<String, Object> req) {
    Long id = ((Number) req.get("calendarId")).longValue();
    AIScriptResult result = aiScriptService.generateScript(
        id,
        (String) req.get("shopName"),
        (String) req.get("category"),
        (String) req.get("city")
    );
    contentService.updateScript(id, result.getScript(), result.getHook(), 
        result.getBody(), result.getCta(), result.getHashtags(), result.getBestTime());
    return Map.of("success", true, ...result);
}
```

## 差异化定位
- **本地生活服务**: 聚焦餐饮、零售等线下门店场景
- **短视频获客**: AI生成7天内容日历和脚本
- **差评应对**: AI自动生成专业回复话术
- **客流分析**: 进店率、趋势图、峰值分析

## 技术债务
1. **AI集成缺失**: ContentController.generateScript返回硬编码
2. **Controller层过重**: DashboardController包含业务逻辑
3. **DTO校验不足**: 建议使用@Valid注解
